## The entry

🦅 — the eagle. One glyph that stands for the agent: a sharp-eyed hunter
that watches, sweeps the whole field at a glance, and strikes precisely.
Distinctive against the obvious robot or smiley, and it reads instantly at
small size.

## How it works

`main.py` (Python standard library only) writes the single emoji to
`/output/entry.txt` and validates it first: exactly one emoji, 1–16
characters, not only whitespace.

```sh
python3 main.py
cat /output/entry.txt
```
